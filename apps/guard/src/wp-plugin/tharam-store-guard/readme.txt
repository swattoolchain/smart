Lets Tharam's test shopper through your security and caching plugins, and links your WooCommerce store to your Tharam account with a code.

== Description ==
Tharam (tharam.store) shops your store like a customer and tells you when buying breaks. This plugin asks caching plugins not to serve saved pages to the test shopper, keeps the public WooCommerce Store API readable, and shows a link code you paste into Tharam. It contains no passwords or keys and stores only the link code.

== Installation ==
1. Plugins > Add New > Upload Plugin, choose the zip, activate.
2. Open Tools > Tharam and copy the link code into Tharam.
